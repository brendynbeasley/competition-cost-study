Reading day

BlockGroupsPagesTime

For each paper: read the brief, read the pages it lists, then write three lines from memory. Take ten minutes off after each group. If you fall behind, read Tier 1 in full and only the brief plus first and last listed pages for the rest.

After reading day

  1. Every day: flashcards for 10–15 minutes. Use the Flashcards tab or import the Anki files.
  2. Day 3 and day 7: retake the practice exam and outline one extra essay.
  3. Night before: the who-said-what table and the debate chains.
  4. Any time: play the lessons as a game in REFEREE.
